# Our Learning Space — GitHub Pages

A static, mobile-friendly homeschool maths hub for one Year 8 learner and two Year 6 learners.

## Deploy
1. Create a GitHub repository (e.g. `homeschool-learning`).
2. Upload the **contents** of this folder to the repository root, retaining `assets/workbooks/` and `assets/videos/`.
3. In GitHub **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and save.
4. Open the GitHub Pages URL shown in Settings. No server or build process is required.

## Notes
- PDF files are A4 workbooks and A3 multiplication charts. Print the A3 charts at A3 / landscape.
- Video files are locally hosted MP4. The two large source files were re-encoded to fit under 25 MB; playback quality may be lower than the originals.
- Each learner has an independent browser-local progress tracker; **progress does not sync across devices**, and clearing browser storage resets it.
- GitHub Pages is public. The workbook PDFs contain answer keys and can be accessed by anyone with the website URL. This is **not** a secure parent-only dashboard.
- Keep personal data, private marks, and student names out of public GitHub repositories.
- Upload only videos you have permission to redistribute publicly. Hosting copyrighted third-party videos on GitHub Pages may require permission even if you have a personal copy.
- GitHub Pages is intended for websites, not large-scale video hosting. If traffic increases, move video assets to an appropriate video hosting platform.
